# Archived Site: Anything iTech Martha's Vineyard (Original Recreation)

## Overview

This folder contains the previous production version of the Anything iTech Martha's Vineyard website. It was archived prior to deploying the new MV Design Studios website.

## Archive Details

- **Date Archived:** April 19, 2026
- **Archived From:** Root `/src`, `/public`, and configuration files
- **Active Site Location:** The current production site now lives in the repository root (`/src`, `/public`)

## Purpose

This archive is retained for:
- Historical reference
- Potential rollback if needed
- Documentation of the previous site structure

## Important Notes

- This archived version is **not part of the active production site**
- The `archive/` folder is excluded from Vercel deployment via `.vercelignore`
- These files will not be built, routed, or served in production

## Restoration

If you need to restore this version:
1. This archive is preserved for manual rollback and reference purposes
2. It is intentionally excluded from deployment
3. To restore, copy the relevant files from this archive back to the repository root
4. Review and test thoroughly before redeploying

## Contents

- `src/` - React/Next.js application source code
- `public/` - Static assets (images, icons, WordPress uploads)
- `package.json` - Dependencies and scripts
- `tsconfig.json` - TypeScript configuration
- `next.config.ts` - Next.js configuration
- Other configuration files

- Service pages (iPhone Repair, Mac Repair, Network Services)
